# KADR Studio

Сайт студии: моушн-дизайн на нейросетях, сайты и мобильные приложения.
Один файл `index.html`, никакой сборки не нужно.

## Как выложить на GitHub Pages

Репозиторий: `davydovserg/Portfolio-D`.

1. Залейте изменения: `git push`.
2. В репозитории откройте **Settings → Pages**, в поле **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
3. Через 1–2 минуты сайт будет по адресу `https://davydovserg.github.io/Portfolio-D/`.

## Что поменять

- Контакты: в `index.html` найдите комментарий `КОНТАКТЫ` и замените Telegram, WhatsApp и почту.
- Видео: ролики лежат в `video/`, скриншоты проектов в `work/`. Новые клипы (MP4, H.264, до 20–30 МБ каждый, без звука для автозапуска).
  GitHub не принимает файлы больше 100 МБ.
